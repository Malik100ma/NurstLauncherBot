# Telegram-бот: клиент + АФК-бот для Minecraft (Node.js)

## Что умеет

- `/start` приветствует по @username (или имени) и показывает кнопки:
  - **Установить клиент** — ссылка на скачивание;
  - **Создать бота** — меню настроек.
- Меню настроек: изменить ник, порт, айпи, пароль и «Назад». Нажимаешь кнопку,
  пишешь значение в чат, после этого снова появляется меню.
- Настройки у каждого пользователя свои, хранятся в `settings.json`
  (пароль лежит там открытым текстом).
- Команды: `/join` — запустить бота на сервере, `/say текст` — написать в чат,
  `/stop` — выключить. Сообщения из игрового чата пересылаются в Telegram,
  при вылете бот переподключается через 15 секунд.

## Запуск на хостинге (Bot-Hosting / Pterodactyl)

Ошибка `No such file or directory: 'node'` была из-за того, что в Python-образе нет
Node.js. Эта версия целиком на Node.js, Python не нужен.

1. В настройках сервера смени Docker-образ на **Node.js** (например `nodejs_22`).
2. Файл запуска (Startup file / Main file) поставь `index.js`.
3. Загрузи `index.js` и `package.json`. Старые `main.py`/`bot.py` и `requirements.txt` удали.
4. Токен: либо переменная окружения `BOT_TOKEN`, либо впиши в `index.js`
   вместо `ВСТАВЬ_ТОКЕН_СЮДА`.
5. Зависимости ставятся из `package.json` (`npm install`). Если панель этого не делает,
   в Startup добавь пакеты `telegraf mineflayer` или выполни `npm install` в консоли.

## Локально

```
npm install
BOT_TOKEN=123:ABC node index.js
```

## Заметки

- `MC_VERSION = null` — версию mineflayer определяет сама. Если сервер 1.21.11
  не подключается, обнови mineflayer: `npm i mineflayer@latest`.
- `MC_AUTH = 'offline'` — для пиратских серверов. Для лицензии поставь `'microsoft'`.
